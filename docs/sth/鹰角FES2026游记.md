# 鹰角FES2026

在学校实践队经历了五六天的上海市内定向越野，决定奖励自己体验一下 『鹰角嘉年华』，遂赴之。

没有准备无料，cos 阴暗大学生前往大型蟑螂集会。

![嘉年华](/images/随便写写/鹰角FES2026游记/嘉年华.jpeg)

岁家官C 是在下午集结的，当时我都准备走了，决定去明日方舟馆再抓几个 coser 集邮，猛然发现这里围了一层一层又一层人，原来是岁家集结+小剧场（比如大哥教小余打太极，望和兄弟姐妹们下棋等），挤了好久才有机位可以拍摄，尽管如此拍摄效果依旧不尽如人意，有点可惜。

终末地那边，庄方宜的官C 我是每次路过都没看到，不过后来在网上也是刷到了，很可惜没看到真人吧。



## 各类活动 / 小游戏

不得不提的是，很多活动 / 小游戏办的差些意思，无聊的同时往往排长队，上午时候明日方舟馆的很多项目都预计 60min 起步，个别甚至达到 120min，而且奖励也少得可怜（有的为小贴纸），望而却步了。相比于去拍官C 或去找 coser 们集邮，这类项目倒是显得食之无味弃之可惜了。

有个干员呼叫台的小游戏，在麦克风前喊出干员代号，屏幕上就会出现 TA 的立绘。我把玛恩纳喊出来了，后面的人集体大喊玛↓恩↑纳\~~~↓

不过个人体验下来斗蛐蛐环节体验感还是不赖的，百来号人站在场地里，通过站左右场地赌哪边会赢。一轮两次，都赌对了：）场景氛围也营造得很好，真是精彩的战斗！



## 集邮

集邮毫无疑问是对的，勇敢的人先享受照片，在结束后修、回看集邮的照片是一件很幸福 ~~（戒断）~~ 的事情。我大部分时间都花在了觅食 coser 老师们并集邮。

不得不提，打光效果真的很影响质量，虽然也能靠后期修就是了。在此严肃批评明日方舟馆的神人灯光，暗的要死（虽然也造就了诸如斗蛐蛐、界园等部分的优秀灯光氛围就是了），大部分情况下集邮的直出效果都很差，更别谈界园那个死人灯光，跟 coser 集邮的时候 coser 自己都绷不住了，我连忙说我后期会修的。有条件建议搭配打光板或者打光灯，没条件就纯依赖后期吧。

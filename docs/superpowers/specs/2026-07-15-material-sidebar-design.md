# Material 原生分类侧栏设计

## 目标

让“校内篇 / CTF篇 / 杂篇”在三栏布局的左侧导航中按文章 `categories` 显示可折叠分类树，交互沿用当前安装的 Material for MkDocs 9.6.20。同步移除页眉右上角的仓库入口，并把个人 GitHub 主页放入“关于”页。

## 实现边界

- 不复制或覆盖 Material 的 `partials/nav-item.html`。
- 不增加自定义折叠 JavaScript。
- 由现有 `hooks/taxonomy.py` 生成嵌套 `.nav.yml`，Material 原生模板负责复选框、箭头、展开状态和移动端抽屉。
- 保持 `study / ctf / sth` 目录及所有文章 URL 不变。
- 篇章首页中的分类树继续保留，与左侧导航使用同一份 front matter 数据。

## 导航层级

生成器去掉每篇文章分类路径的篇章根节点，再将剩余路径写入该篇章的 `.nav.yml`。篇章 `index.md` 始终排在第一项，并由 `navigation.indexes` 作为篇章标题的入口。

校内篇示例：

```text
校内篇
└─ 笔记
   ├─ 数据结构
   │  ├─ 数据结构实验复习整理
   │  └─ 数据结构复习整理
   ├─ 程序设计(A)(C)
   │  └─ 程序设计(A)(C)作业
   └─ 线性代数
      └─ 线性代数_矩阵笔记
```

CTF篇显示 `WP → 比赛名 → WP文章`；杂篇显示 `Linux / 流光协奏 / 游记 → 对应文章`。同一分类叶节点内按文章日期从新到旧排列，分类名保持稳定的字典序。

## 展开行为

- 阅读文章时，Material 根据 `nav_item.active` 自动展开当前文章所在的完整分类分支。
- 其他同级分类默认折叠，可使用原生箭头手动展开。
- 进入篇章首页时没有活动文章分支，因此分类默认折叠。
- 移动端继续使用 Material 原生导航抽屉，不复制桌面侧栏结构。

## 样式

保留现有侧栏拖拽宽度和悬停效果，在 `leftsidebar.css` 中补充：

- 当前文章链接使用主题蓝色。
- 当前文章链接左侧显示短蓝色竖条，浅色模式使用 `#6171F5`，深色模式使用 `#7DAFE9`。
- 嵌套层级使用 Material 原生缩进与箭头，不添加卡片背景或额外边框。
- 聚焦状态可见，并尊重 `prefers-reduced-motion`。

## GitHub 入口

- 从 `mkdocs.yml` 删除 `repo_url`，使页眉右上角不再生成仓库入口。
- 在 `docs/about/index.md` 的个人资料列表中增加 `GitHub：[TangentZX](https://github.com/TangentZX)`。
- 本次不增加文章页、页脚或其他位置的 GitHub 图标。

## 自动更新与异常处理

新增文章只需填写合法的篇章根分类与后续分类路径。生成器继续采用“内容不变则不写文件”。如果文章分类不属于其所在篇章根节点，该文章仍保留在构建中，但不会进入该篇章的分类树；测试会覆盖当前九篇文章的合法路径。

## 验证

- 单元测试断言三份 `.nav.yml` 的完整嵌套结构和日期顺序。
- 严格构建后检查当前文章分支含 `checked` 的 Material 原生导航开关，其他分支保持未选中。
- 浏览器检查桌面三栏、移动端抽屉、深浅主题、当前项蓝色竖条和无横向溢出。
- 构建页眉不再包含 GitHub 仓库入口，“关于”页包含个人 GitHub 主页。

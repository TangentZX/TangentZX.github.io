# 分类连接线树样式设计

## 目标

增强篇章首页与归档分类页中文件树的层级辨识度，同时维持现有博客轻盈、留白充足的视觉语言。

适用页面：

- `docs/study/index.md`
- `docs/ctf/index.md`
- `docs/sth/index.md`
- `docs/archive/categories.md`

## 约束

- 保留现有文章 Front Matter、分类路径、文章 URL 和日期倒序逻辑。
- 保留 `hooks/taxonomy.py` 当前输出的 Markdown 标题与文章列表结构。
- 亮色主题使用 `#6171F5`，深色主题使用 `#7DAFE9`。
- 不把分类树改成厚重的整块卡片，也不增加依赖 JavaScript 的折叠交互。
- 标签页与标签词云不在本次范围内。

## 视觉层级

### 一级分类

一级分类是树根。标题左侧使用较粗的主题色竖栏，字号与字重高于下级分类，并在不同一级分类之间保留充足的垂直间距。

### 二级及更深分类

二级及更深分类逐级增加缩进。每一级使用细竖线表示所属分支，并通过短横线连接分类标题或文章项。连接线颜色随层级加深而降低不透明度，避免页面出现过重的网格感。

分类标题的字号、字重和上下间距随深度逐级收敛，但不得小于正文文章标题。

### 文章项

文章显示为轻量行式条目：

- 日期占据固定宽度，使用等宽数字并降低视觉权重；
- 标题在同一分类内保持左侧对齐；
- 条目背景默认透明；
- 悬停和键盘聚焦时显示很淡的主题色背景；
- 长标题允许自然换行，不截断正文标题。

## 主题与响应式

亮色模式的主连接线使用 `#6171F5`，深色模式使用 `#7DAFE9`。更深层连接线通过颜色混合或透明度生成，不额外引入不相关的强调色。

在窄屏下：

- 减小每级缩进；
- 缩短日期列宽度并保持日期完整；
- 文章标题换行后与标题起始位置对齐；
- 不产生横向滚动条。

## 实现边界

主要修改 `docs/resources/css/taxonomy.css`。现有 `.taxonomy-categories` 容器继续作为样式作用域，避免影响普通文章中的标题和列表。

若仅靠现有 Markdown 生成的 HTML 无法稳定表达连续连接线，可对 `hooks/taxonomy.py` 做最小的语义化包装调整，但不得改变分类数据、排序方式或链接地址。

## 验证

- 校内篇验证三级结构：`笔记 → 高等数学 → 文章`。
- CTF 篇验证三级结构：`WP → 赛事 → 文章`。
- 杂篇验证二级结构与同分类多篇文章。
- 归档分类页验证多个一级分类连续出现时的分区间距。
- 分别检查亮色、深色、桌面和手机宽度。
- 验证鼠标悬停、键盘聚焦和长标题换行。
- 运行 MkDocs 严格构建与现有自动化测试。
